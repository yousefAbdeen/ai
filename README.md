# Coding Assistant

AI software engineering skill for OpenCode.

## What it does

Coding Assistant helps OpenCode:

- Understand an existing project
- Plan features
- Implement features
- Fix bugs
- Review code
- Run verification

## Installation

### Windows

Run:

irm https://raw.githubusercontent.com/YOUR_USERNAME/coding-assistant/main/install.ps1 | iex

### Manual Installation

Clone:

git clone https://github.com/YOUR_USERNAME/coding-assistant.git

Then follow the installation instructions.

## Usage

### Feature

/feature Add product search

### Review

/review

### Fix
